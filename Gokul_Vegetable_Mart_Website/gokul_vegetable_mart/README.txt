GOKUL VEGETABLE MART WEBSITE

1. Extract this ZIP file.
2. Keep index.html and the assets folder together.
3. Open index.html in Chrome to preview the website.
4. To change vegetable prices, edit the vegetables array near the bottom of index.html.
5. WhatsApp order number is configured as 917093200220.

The banner and peacock-feather theme images are in assets/.
The banner states 0% platform fee and delivery charges based on distance.
Prices are sample values; replace them with the shop's actual prices.

This is a static front-end prototype. Orders are sent to WhatsApp; there is no database or admin panel yet.
